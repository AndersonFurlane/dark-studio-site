Política de Privacidade

Dark Studio · última atualização: 1º de novembro de 2026

O Dark Studio é uma ferramenta interna usada exclusivamente pelo seu desenvolvedor, Anderson Furlane Martins, para gerenciar os seus próprios canais do YouTube. Ela não tem usuários externos.

Serviços de API do YouTube

O Dark Studio usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Quais dados são acessados

Com a autorização do proprietário dos canais (escopo https://www.googleapis.com/auth/youtube), a ferramenta acessa apenas dados dos próprios canais: identificação e nome do canal, vídeos enviados pela ferramenta, playlists e configurações de identidade visual do canal. Não são acessados dados de espectadores, comentários, inscritos ou de qualquer outra pessoa.

Como os dados são usados

Os dados são usados somente para enviar e gerenciar os vídeos e playlists dos canais do proprietário. Não há publicidade, análise de comportamento nem perfilamento.

Armazenamento e compartilhamento

  • Os tokens de acesso OAuth ficam armazenados apenas no computador do proprietário, em arquivo com acesso restrito ao seu usuário do sistema;
  • Os metadados dos vídeos (ID do vídeo, título, status de privacidade, playlist) ficam no banco de dados local da ferramenta;
  • Nenhum dado é vendido, compartilhado ou transferido a terceiros;
  • Não são usados cookies nem outras tecnologias de rastreamento.

Retenção e exclusão

Os dados ficam armazenados enquanto a ferramenta estiver em uso. O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: myaccount.google.com/permissions. Após a revogação, os tokens deixam de funcionar e são apagados do computador local. Dados obtidos da API que não forem mais necessários são excluídos em até 30 dias.

Privacy Policy (English)

Dark Studio is an internal tool used solely by its developer, Anderson Furlane Martins, to manage his own YouTube channels. It has no external users.

YouTube API Services. Dark Studio uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

Data accessed. With the channel owner's authorization (scope https://www.googleapis.com/auth/youtube), the tool only accesses data of the owner's own channels: channel ID and title, videos uploaded through the tool, playlists and channel branding settings. No data about viewers, comments, subscribers or any other person is accessed.

Use. Data is used only to upload and manage the owner's videos and playlists. No advertising, behavioral analysis or profiling.

Storage and sharing. OAuth tokens are stored only on the owner's computer, in a file readable only by the owner's system user. Video metadata (video ID, title, privacy status, playlist) is kept in the tool's local database. No data is sold, shared or transferred to third parties. No cookies or tracking technologies are used.

Retention and deletion. Data is kept while the tool is in use. Access can be revoked at any time at myaccount.google.com/permissions; after revocation the tokens stop working and are deleted from the local computer. API data that is no longer needed is deleted within 30 days.
